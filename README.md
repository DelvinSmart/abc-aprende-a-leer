# ABC — Aprende a leer (descargas)

Aquí se publican los instaladores (APK) de **ABC**, una app para que los niños aprendan a leer desde cero, con una mascota que les habla.

- **Descargar la última versión para Android:** [ABC.apk](https://github.com/DelvinSmart/abc-aprende-a-leer/releases/latest/download/ABC.apk)
- **Página web y panel de padres:** https://leo-conmigo-app.web.app

## Cómo instalarlo
1. Abre el enlace de arriba desde el teléfono Android (Android 7 o más nuevo).
2. Abre el archivo `ABC.apk` descargado.
3. Si el teléfono lo pide, permite instalar apps de esa fuente.
4. Toca **Instalar**. Si aparece Play Protect, toca **Más detalles → Instalar de todas formas** (sale porque no viene de la tienda).

Para actualizar, instala la versión nueva encima: el progreso no se pierde.
